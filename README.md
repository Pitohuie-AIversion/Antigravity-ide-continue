# 🚀 Antigravity Continuous Runner (无人值守·自动继续监听守护程序)

专门为 **Antigravity IDE** 量身定制的对话自动监控与自动继续守护程序。

---

## 💡 为什么需要它？

在进行复杂的大型任务、全项目重构或多步代码编写时，Antigravity IDE 的 Agent 往往会在完成一个子阶段后暂停并等待用户输入（例如：“请问是否继续？”、“第一步已完成，下一步如何处理？”），或者由于单轮输出步数上限而进入等待态。

如果你需要离开电脑、进行长任务测试或希望 AI **完全自主连续执行**，本工具可以实现：
1. **自动监控当前会话**：毫秒级实时读取 Antigravity 原生 Transcript 事件流。
2. **精准状态识别**：精确区分 AI 正在思考执行（Busy）、冷却确认（Stabilizing）、等待输入（Idle）还是等待用户回答选择题（Waiting Decision）。
3. **原生无感注入**：基于 Antigravity 原生语言服务协议（`language_server` / `agentapi` RPC），直接将继续指令推入会话队列，**不占用焦点、不抢夺鼠标键盘、窗口最小化依然完美工作**！
4. **智能防爆流与防死循环**：内置冷却防抖机制、最大轮数限制与完成关键字检测（当 AI 明确回复“所有任务已完成”时自动收尾停机并播放提示音）。

---

### 核心特性

- 🚀 **多会话并发巡航矩阵 (Multi-Session Fleet Matrix)**：同时纳管 1 至 N 个会话，多线程并行监控步数与执行状态，各会话独立倒计时与静默注入。
- 🔄 **动态服务自愈引擎 (Dynamic LS & CSRF Discovery)**：IDE 切换 Google 账号或重启后，全自动在 `<20ms` 内重新发现动态 gRPC 端口并提取专属 `--csrf_token`，彻底杜绝换号注入失败。
- 🌐 **跨设备混合并发**：支持在同一控制面板中同时纳管 **本地 Windows 开发区** 与 **远程 Linux SSH 节点（如恒源云 seetacloud-westc）**。
- ⚡ **零死锁与双栈极速服务**：基于 Python 可重入锁 (`RLock`) 与 IPv4/IPv6 Dual-Stack HTTP 服务器，毫秒级即时响应。
- 🔍 **矩阵检索、筛选与排序工具栏**：支持全字段搜索（标题/ID/设备/状态）、分类过滤胶囊（全部/巡航中/思考中/已暂停/本地/恒源云）、多维度排序（心跳/步数/名称）。
- 🎛️ **批量操作面板 (Batch Operations Toolbar)**：支持勾选多个卡片或全选，一键批量开启、批量暂停、批量修改提示词与冷却秒数、批量移出。
- 💾 **全量配置备份与导入 (Backup & Restore)**：支持一键导出当前纳管会话与 Webhook 配置为 JSON，支持从文件或剪贴板导入合并，便于跨设备同步。
- ⏱️ **执行耗时与卡死智能预警**：卡片实时展示当前思考步耗时（如 `Step 4656 · 1m 24s`），步骤超 5 分钟自动点亮黄色呼吸预警胶囊。
- 📜 **控制台日志检索与等级过滤**：支持关键词秒级搜索与等级胶囊切换（`全部` / `⚡ 注入` / `✅ 成功` / `⚠️ 警告` / `❌ 错误`）。
- 💬 **提示词宏指令库 (Prompt Macros)**：内置一键填入 `[/goal] 全局开发`、`[/plan] 规划阶段`、`⚡ 继续推进任务`、`🧪 自测与验证`、`📊 交付总结报告` 等常用快捷指令。
- 🔔 **全平台自动化告警推送**：支持飞书、钉钉、企业微信机器人 Webhook 联动通知。
- 🛡️ **智能防爆流与完工检测**：自动消抖冷却，检测到“所有任务已完成”时安全停机并播放 Web Audio 空灵提示音。


## ⚡ 极速启动方式

### 方式 1：双击运行原生桌面程序 `AntigravityAutoPilot.exe`（终极便捷 ⭐⭐⭐⭐⭐）
直接双击运行目录下的 **`AntigravityAutoPilot.exe`** 或桌面快捷方式 **`Antigravity Auto-Pilot`**：
- 🖥️ **无终端黑框**：纯原生 Windows 桌面程序，不会残留任何黑框控制台窗口；
- 🌐 **启动即拉起看板**：自动在默认浏览器唤起 **`http://localhost:5300`**；
- 🖱️ **任务栏系统托盘常驻**：右下角提供雷电图标，支持随时右键快速「打开面板」、「启动巡航」、「暂停巡航」或安全「退出」；
- 🔄 **防重入与单实例检测**：多次双击自动唤醒既有浏览器窗口，不重复占用端口。

---

### 方式 2：批处理启动器 `start_ui.bat`
双击根目录下的 **`start_ui.bat`**，将自动优先拉起原生程序或在后台以静默模式载入托盘服务。

- **多会话矩阵看板**：直观展示所有正在并发巡航的对话卡片；
- **独立开关控制**：卡片右上角配备 iOS 风格滑动开关，随时单独暂停或开启某会话；
- **全局一键动作**：支持 `▶ 全部启动自驱巡航`、`⏹ 全部暂停自驱` 与 `⚡ 全矩阵立即注入一次`；
- **一键纳管新会话**：在下方选择浏览设备（本地电脑或恒源云节点），选择对话后一键加入监控池；
- **跨设备多路复用**：自动保活远程 SSH 隧道并对接远程 AgentAPI，实现本地与云端混合并发；
- **实时审计控制台**：嵌入式终端流，带有会话来源标识 `[本地/b363...]` 或 `[恒源云/d8b0...]`，清晰追踪每一步动作。

### 方式 2：CLI 终端极简模式
直接在资源管理器中双击打开 **`start.bat`**，或在命令行运行：

```bash
# 1. 默认启动：扫描最近活跃的对话，交互式选择
python main.py

# 2. 自动秒挂载最新活跃的对话（无需人工选择，即开即用）
python main.py --latest

# 3. 指定具体的对话 ID 进行监控
python main.py -c b3636e97-3c55-494b-82c5-6b9b1accf5fe

# 4. 自定义继续提示词与最大轮数
python main.py --latest -p "请继续编写单元测试并修复所有报错" --max-turns 30
```

## ⌨️ 运行时快捷键

在监控运行窗口中，支持以下单键无回车热键：

| 快捷键 | 功能说明 |
| :---: | :--- |
| **`[P]` 或 `[空格]`** | **暂停 / 恢复**：手动暂停自动继续，或恢复监听 |
| **`[C]`** | **立即强行触发**：不等倒计时，立即发送一次继续指令 |
| **`[L]`** | **查看日志**：在终端打印最近 2 条详细步骤信息 |
| **`[Q]`** | **安全退出**：平稳退出守护程序并打印本次运行统计 |

## ⚙️ 配置文件说明 (`config.json`)

程序首次运行时会自动读取同目录下的 `config.json`，各项参数如下：

```json
{
  // 模型回答结束后的冷却确认秒数（防止工具尚未完全退出误判空闲）
  "idle_delay_seconds": 6,

  // 最大自动继续轮数（防死循环/防 token 异常消耗）
  "max_turns": 50,

  // 默认发送给 Antigravity IDE 的继续提示词
  "continue_prompt": "请继续推进当前任务，执行下一步。若全部任务均已完成，请在回复中明确说明【所有任务已完成】。",

  // 任务完成检测关键字列表（命中其中任意一个将自动停止监控并提示）
  "completion_keywords": [
    "所有任务已完成",
    "全部任务已完成",
    "所有需求已完成",
    "所有需求均已完成",
    "已全部完成",
    "代码修改已全部完成",
    "【所有任务已完成】",
    "all tasks completed",
    "all tasks are completed",
    "task completed successfully"
  ],

  // 当模型使用 ask_question 明确向用户提出选择/提问时是否暂停等待人工决策
  "pause_on_question": true,

  // 触发继续时是否播放系统轻音提示
  "sound_alert": true,

  // 是否默认自动选择最新的活动对话
  "auto_select_latest": true
}
```

## 🔍 技术原理说明

1. **事件流捕获**：
   Antigravity IDE 会在本地目录 `~/.gemini/antigravity-ide/brain/<conv_id>/.system_generated/logs/transcript.jsonl` 持续记录完整的运行时轨迹。守护程序使用高效尾部增量解析提取最新状态。
2. **原生 RPC 驱动**：
   通过调用 Antigravity IDE 随身附带的 `language_server_windows_x64.exe agentapi send-message <conv_id> <content>`，将消息无缝提交到底层 gRPC/IPC 消息管道。
3. **响应式唤醒**：
   消息提交后，Antigravity 内核的 `Reactive Wakeup` 机制会自动解冻等待中的模型进程，将继续指令当做用户新输入推入当前对话上下文，实现全自动运转。
